# Personal Claude Code tips, layered on top of the ones bundled with
# claude-tips (github.com/FinalAngel/claude-tips). One per line; blank lines
# and # comments are skipped. Takes effect on the next turn.
#
# This file is for tips that are yours alone — machine-specific habits, things
# about this setup. A tip that would help anyone belongs in the plugin itself:
# edit tips/tips.txt in the repo and push, rather than adding it here.

/plugin marketplace update — pull the newest claude-tips list without reinstalling
/output-style [style] — list output styles or switch to one, for when you want terser or more explanatory replies
/update-config [request] — describe a settings change like allowing a command or adding a hook, and Claude edits settings.json for you
/claude-in-chrome [task] — have Claude test a page, fill a form or read console logs in your browser
/slides [brief] — turn a brief into a Claude Slides deck as an artifact, no .pptx wrangling
